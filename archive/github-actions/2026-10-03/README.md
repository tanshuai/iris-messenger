# Archived GitHub Actions

The repository owner retired these obsolete or inherited workflows as part of the GitHub Actions efficiency cleanup. The exact workflow bytes and local dependency/code snapshots are preserved here; shared application source remains in its original location.

`manifest.json` records the original commit, blob IDs, SHA-256 hashes, consumers, retirement reasons and recovery instructions. Existing run history and published releases remain available. Files in this archive are data, not active workflow entrypoints.

Restore only through a reviewed PR after validating the current business need, runtime support, destination and credential names. Passive vulnerability alerts were not disabled.
